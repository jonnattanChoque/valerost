# Tinte

*Category: history*

La búsqueda de la perfección genética terminó en una "corrosión" biológica. El Tinte es el resultado de un sistema de edición genética (como CRISPR-Cas9 de próxima generación) que se volvió inestable, las habilidades no son "poderes", sino errores de cálculo en la optimización del ADN.

## El Protocolo Tinte

1. **Nodo de Integridad Tissular (El Cuerpo como Contenedor)**
   Originalmente diseñado para eliminar el envejecimiento externo y las lesiones físicas.
   - Rama Dérmica/Colágena:
     - Habilidad: Dureza Dérmica [[Blindaje]].
   - Rama de Elasticidad Estructural:
     - Habilidad: Hiper-plasticidad [[Maleable]].

2. **Nodo de Potencia Motora (El Cuerpo como Motor)**
   Originalmente diseñado para la eficiencia atlética y el fin de la debilidad muscular.
   - Rama de Reclutamiento Neuromuscular:
     - Habilidad: Fuerza por Ira [[Berserker]]

   - Rama de Soporte Óseo:
     - Habilidad: Densidad Reactiva [[Marfil]].

3. **Nodo de Homeostasis Sistémica (El Cuerpo como Laboratorio)**
   Originalmente diseñado para la salud interna perpetua y la autonomía energética.
   - Rama de Regeneración Celular:
     - Habilidad: Curación Acelerada [[Lazaro]].

   - Rama Metabólica:
     - Habilidad: Termogénesis / Anoxia [[Termogenesis]].

4. **Nodo de Interfaz y Proyección (El Cuerpo como Antena)**
   Originalmente diseñado para la comunicación telepática y el control social.
   - Rama de Proyección Bio-Eléctrica:
     - Habilidad: Telequinesis [[Resonador]].

   - Rama de Invasión Neural:
     - Habilidad: Control Motor ([[Titiritero]]).

     - Habilidad: Manipulación de Memoria ([[Invasor]]).

     - Habilidad: Control Visceral ([[Verdugo]]).
